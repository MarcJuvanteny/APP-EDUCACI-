# Competències per assignatura — Currículum Catalunya (Primària)
 
## Escales d'avaluació
- NA = No Assolit (1–4)
- AS = Assoliment Suficient (5–6)
- AN = Assoliment Notable (7–8)
- AE = Assoliment Excel·lent (9–10)

|  | **6.2 Organiza y comunica la información.** | Tiene dificultades para organizar y comunicar la información. | Organiza y comunica información básica con ayuda. | Organiza la información de manera clara y la comunica adecuadamente. | Organiza la información de manera eficiente y la comunica con claridad, precisión y autonomía. |
| **CE 7. Lectura** | **7.1 Comprende textos adecuados al nivel.** | Tiene dificultades para comprender textos adecuados a su nivel. | Comprende textos sencillos con alguna ayuda. | Comprende adecuadamente los textos trabajados. | Comprende textos diversos con profundidad y autonomía. |
|  | **7.2 Muestra interés por la lectura.** | Muestra poco interés por la lectura. | Muestra interés ocasional por la lectura. | Muestra interés habitual y una actitud positiva hacia la lectura. | Muestra un interés constante y disfruta de la lectura de manera autónoma. |

|  | **8.2 Transmite información básica.** | Tiene dificultades para transmitir información básica. | Transmite información básica con apoyo. | Transmite información básica de manera clara y adecuada. | Transmite información de manera precisa, clara y adaptada al contexto y al destinatario. |

|  | **9.2 Utiliza estrategias para mejorar el aprendizaje.** | Tiene dificultades para utilizar estrategias de aprendizaje. | Utiliza algunas estrategias con ayuda. | Utiliza estrategias adecuadas para mejorar su aprendizaje. | Selecciona y aplica de manera autónoma estrategias eficaces para mejorar su aprendizaje. |

|  | **10.2 Participa de manera cooperativa y respetuosa.** | Tiene dificultades para participar de manera cooperativa y respetuosa. | Participa de manera adecuada con algún apoyo. | Participa activamente, cooperando y respetando a los demás. | Participa con iniciativa, facilita la cooperación y contribuye a crear un clima de respeto y convivencia. |
